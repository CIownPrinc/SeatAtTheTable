# Seat at the Table release history

The game is now **V5.0: The Living City**. This is the missions-and-map gameplay era: longer
mission chains, real in-person destinations, contacts and taxis, a rebuilt expanding map,
and optional outskirt experiences.

## V5.0 — The Living City

Started at `5577453` on 2026-07-22 with mission-backed event flow. The current release adds
mission chains, progressive onboarding, larger named outskirts, and activities that reward
driving somewhere rather than opening another menu.

## V4.0 — The Connected City

Started at `4854b76` on 2026-07-21 with the diegetic phone and unique in-person interactions.
This is the phone, map overhaul, and amenity era.

## V3.0 — The City Map

Started at `e600ccf` on 2026-07-12 with the full Three.js world, minimap, and road-constrained
driving. It established the map-first version of the game.

## V2.0 — The Noir Interface

Started at `a722287` on 2026-07-15 with the complete UI and theme redesign, followed by the
V2.1 and V2.2 interface passes.

## V1.0 — First Seat

Started at `12bdca7` on 2026-07-11: the original playable crime, business, and political
tycoon game.

Git commit subjects are historical records. They are intentionally not rewritten: changing
published commit IDs would force every existing clone and branch to reconcile a different
history. This file gives the same version context without breaking the repository.
