# Seat at the Table — V5.0
A browser-based crime, business, and political tycoon game set in Chicago. The player begins as an immigrant fleeing gang violence in Delhi and must build an empire through legitimate businesses, criminal enterprises, real estate, banking, territory control, and eventually politics.

## Version timeline

The version names describe the big moments where the game changed shape for the player. They
are release markers tied to the real Git history, rather than rewritten commit messages.

| Version | Era | Started at | What changed |
| --- | --- | --- | --- |
| **V1.0 — First Seat** | Original game | `12bdca7` · 2026-07-11 | The first playable crime, business, and political tycoon: build an operation, make money, gain standing, and grow into city power. |
| **V2.0 — The Noir Interface** | UI redesign | `a722287` · 2026-07-15 | The project found its visual voice: the noir dossier interface, theme system, clearer screens, then the V2.1/V2.2 layout and usability passes. |
| **V3.0 — The City Map** | Map-first gameplay | `e600ccf` · 2026-07-12 | The flat game became a navigable Three.js city with a minimap, road-constrained driving, buildings, traffic, pedestrians, and map-led play. |
| **V4.0 — The Connected City** | Phone, places, and amenities | `4854b76` · 2026-07-21 | The diegetic phone arrived alongside real in-person interactions, multiple banks, shops, interiors, map search, GPS, and small activities around the city. |
| **V5.0 — The Living City** | Missions and expanding world | `5577453` · 2026-07-22 | Story missions became physical multi-stage scenes with saved consequences; the city expanded into named outskirts, contacts and taxis, map-first onboarding, and optional destination activities. |

V5.0 is the current era. Its work is focused on making the map a place to participate in:
missions happen at locations, the outskirts provide reasons to drive out, and choices show
their exact gameplay consequences.

For a slightly fuller release record, see the repository-level [release history](../CHANGELOG.md).
